Options Event-Risk Calendar: examples

Which scheduled market-moving events land before your option expires? Enter expiration dates (or "next N monthly expirations") and get one row per event: CPI, jobs report, PPI, GDP, PCE, retail sales, FOMC, Treasury auctions, plus rule-computed opex, VIX settlement and NYSE holidays. Each row has the time in ET, an impact tier, days and trading days before expiration, and the official source link. Data comes only from BLS, BEA, Census, the Federal Reserve and the U.S. Treasury.

Open on Apify Store

Educational, not advice. This is a scheduling tool for education and research, not investment, trading or tax advice. Agencies can reschedule releases and exchanges can close unexpectedly. Always confirm critical dates on the official source linked in each row. No consensus forecasts are included.

Example 3: daily alerts for new or moved dates

{ "nextMonthlyExpirations": 3, "minImpact": "high", "alertMode": true, "stateStoreName": "my-macro-alerts", "windowMode": "sincePreviousExpiration" }

Schedule it daily. The first run returns everything as new. Later runs return only events that are new or whose date or time moved, with the previous time. In our live test the rerun returned 0 rows.
